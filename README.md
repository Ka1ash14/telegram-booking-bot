# Бот записи к мастеру (Telegram)

Бот для салона, барбершопа, репетитора или любого мастера, который работает по записи.

## Что умеет
- Выбор услуги с ценой → дня → свободного времени (занятое время не показывается).
- Сбор имени и телефона (можно отправить номер одной кнопкой).
- Подтверждение записи и защита от двойной записи на одно время.
- «Мои записи»: клиент видит свои записи и может отменить их.
- Мастеру приходят уведомления о новых записях и отменах.
- Команда `/admin` для мастера: список всех предстоящих записей.
- Данные хранятся в файле `bookings.db` (SQLite), отдельный сервер базы не нужен.

## Запуск

1. **Создайте бота.** В Telegram откройте @BotFather → `/newbot` → придумайте имя и username (должен заканчиваться на `bot`). BotFather пришлёт токен вида `123456789:AA...`.
2. **Узнайте свой ID.** Напишите боту @userinfobot — он ответит вашим числовым ID. На этот ID будут приходить уведомления о записях.
3. **Создайте файл `.env`** в папке с ботом (скопируйте `.env.example` и переименуйте) и впишите свои данные:
   ```
   BOT_TOKEN=123456789:AA...
   ADMIN_ID=123456789
   ```
4. **Установите библиотеки.** Откройте терминал в папке с ботом:
   - Windows: `pip install -r requirements.txt`
   - Mac: `pip3 install -r requirements.txt`
5. **Запустите:**
   - Windows: `python bot.py`
   - Mac: `python3 bot.py`

   Появится строка «Бот запущен». Откройте своего бота в Telegram и нажмите «Старт».

Бот работает, пока открыт терминал. Чтобы он работал круглосуточно, его размещают на сервере (VPS) — это следующий шаг.

## Настройка под клиента
Всё меняется в начале файла `bot.py`:
- `SERVICES` — список услуг и цены;
- `WORK_START`, `WORK_END` — рабочие часы;
- `DAYS_AHEAD` — на сколько дней вперёд можно записаться;
- `DAYS_OFF` — выходные дни (0 = пн … 6 = вс);
- текст в функции `contacts` — адрес и телефон.

## Технологии
Python 3.10+, aiogram 3, SQLite, python-dotenv.
